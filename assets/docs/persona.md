# Persona

## Inquiry events webhook testing

Для тестирования работы Persona Webhook выполни следующие шаги:

1. В локальном окружении в директории проекта sona-backend запусти ngrok командой

   ```bash
   npm run ngrok
   ```

   Сохрани url, который вернется в ответе.

2. Запусти проект в режиме разработки

   ```bash
   npm run dev
   ```

3. Перейди в меню настройки вебхуков в дашборде Persona [по ссылке](https://app.withpersona.com/dashboard/webhooks).
4. Выбери персональный вебхук. Например, `nikita-dev-hook`. Разделение хуков позволяет вести параллельную разработку в условиях динамического url который генерируется ngrok при старте.
5. Справа в меню **Info** в строке **URL** введи url полученный на шаге 1.

Бэкенд часть вебхука настроена. Для проведения тестов можно использовать два варианта: оригинальную верификацию на клиенте и синтетическую верификацию, которую можно создать в дашборде Persona. Рассмотрим второй вариант

1. Перейди в дашборд Persona по [ссылке](https://app.withpersona.com/dashboard/home)
2. В разделе **Identity** выбери **Inquiries** => **All Inquiries**
3. В правом верхнем углу нажми кнопку **Create inquiry**. Выбери нужный шаблон (_template_) и нажми **Create Inquiry**. По предложенной ссылки ты сможешь пройти верификацию по заданному шаблону.

Все события можно отслеживать по логам express сервера.
Синтетический вариант верификации усложняет взаимодействие с базой данных, так как вебхук-события будут отравлять идентификаторы inquiryId, которые не привязаны ни к одной из записей в базе данных.
