# Основная логика

1. **Фиксированная цена**: 1 TTK = $100
2. **Динамическая конвертация** SOL → USD через оракул Pyth Network
3. **Автоматический расчёт**:
   `Кол-во TTK = (Внесённые SOL × текущий курс SOL/USD) / 100`

## Этапы реализации

### 1. Создание токена (5 минут)

```bash
spl-token create-token --decimals 0 --initial-supply 1000
```

text

- Фиксированный supply: 1000 TTK
- Без возможности дополнительного минта

### 2. Интеграция оракула цены

- Используйте Pyth Network для получения курса SOL/USD в реальном времени
- Альтернатива: CoinGecko API (бесплатно до 30 запросов/минуту)

### 3. Механика покупки

1. Пользователь отправляет SOL
2. Контракт запрашивает текущий курс SOL/USD
3. Рассчитывает количество TTK:  
   `TTK = (SOL × Price) / 100`
4. Токены автоматически зачисляются на кошелёк

### 4. Дивидендная система

- Ежемесячный снапшот через Solana API
- Ручная отправка SOL пропорционально доле TTK
- Формула:  
  `Выплата = (Ваши TTK / 1000) × Общий пул дивидендов`

## Упрощения для быстрого старта

1. Заменить оракул на ручной ввод курса
2. Использовать готовый шаблон dApp от Solana Cookbook
3. Для дивидендов — разовые выплаты через Phantom Wallet

Пример расчёта при курсе 1 SOL = $150:
Внесено: 2 SOL → $300 → 3 TTK
Дивидендный пул: $1000 → 10 SOL
Ваша выплата: (3/1000) × 10 SOL = 0.03 SOL
