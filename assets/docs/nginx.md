# Проектная структура и работа системы

## Описание работы

### 1. Контроль портов VPS

- Настроенный брандмауэр контролирует доступ к портам VPS.

### 2. Docker-контейнеры и сеть

- Все сервисы работают в изолированной сети `site`.

#### Nginx

- Проксирует запросы:
  - **HTTP (80)** → **HTTPS (443)** с SSL от Let's Encrypt.
  - **Frontend**: отображение веб-страницы.
  - **Backend**: обработка запросов на `/api/`.

#### Backend и База данных

- **Взаимодействие**: Backend общается с базой данных напрямую через имя контейнера (например, `db`), без использования
  внешних IP или портов.
- **Сеть**: Внутри изолированной сети Docker `site`, где доступ осуществляется по внутренним адресам и именам
  контейнеров.

### 3. Преимущества

- Изоляция сети: доступ только через Nginx.
- Безопасность: порты сервисов скрыты.
- Простота управления через Docker Compose.

## Основные файлы

- `docker-compose.yml`: Конфигурация сервисов.
- `nginx.conf`: Настройки проксирования.
