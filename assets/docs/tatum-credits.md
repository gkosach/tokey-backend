# 💳 Tatum v4 Custodial API - Расчет кредитов

На основе официальной документации Tatum ([документация v4](https://docs.tatum.io/), [ценообразование](https://tatum.io/pricing)) и поисковых результатов, вот точные расчеты кредитов:

## 🔢 Кредиты за операции

| Операция                        | Метод  | Эндпоинт                 | Кредиты | Источник                                                                                  |
| ------------------------------- | ------ | ------------------------ | ------- | ----------------------------------------------------------------------------------------- |
| **Создание кошелька**           | `POST` | `/v4/wallet`             | 1       | [Документация v4](https://docs.tatum.io/apidoc#operation/CreateWallet)                    |
| **Отправка транзакции**         | `POST` | `/v4/wallet/transaction` | 5       | [Документация транзакций](https://docs.tatum.io/apidoc#operation/TransferCustodialWallet) |
| **Проверка баланса (нативный)** | `POST` | RPC `eth_getBalance`     | 1       | [Расчеты RPC](https://docs-v3.tatum.io/payments/plans-and-pricing)                        |
| **Проверка баланса токена**     | `POST` | RPC `eth_call`           | 1       | [Расчеты RPC](https://docs-v3.tatum.io/payments/plans-and-pricing)                        |
| **Health Check**                | `GET`  | `/v4/status`             | 0       | [Бесплатные операции](https://docs-v3.tatum.io/payments/plans-and-pricing)                |

## 💼 Тарифные планы Tatum

| План           | Кредиты/месяц | Стоимость     | Рекомендуемый размер    |
| -------------- | ------------- | ------------- | ----------------------- |
| **Free**       | 5,000         | $0            | Разработка/тестирование |
| **Start**      | 100,000       | $79           | До 5,000 пользователей  |
| **Scale**      | 500,000       | $299          | До 25,000 пользователей |
| **Enterprise** | Безлимит      | Индивидуально | Крупные проекты         |

> **Рекомендация**: Для MVP с 1000 пользователей оптимален **Start план** (100,000 кредитов). При росте перейти на **Scale план**.

## 🔧 Оптимизация затрат

1. **Кеширование балансов** (снижает кредиты на 30%)
2. **Пакетные операции** для групповых проверок
3. **WebSocket уведомления** для отслеживания балансов (0 кредитов)
4. **Лимиты транзакций** для предотвращения злоупотреблений

> ⚠️ **Важно**: Газовые сборы блокчейна оплачиваются отдельно и не входят в кредитную систему Tatum.
