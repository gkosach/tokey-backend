# Monthly Costs and Functionality Overview

## **Aezo**

- **Cost**: $37 per month
- **Functions**:
  - Hosting for:
    - Backend server (Nginx)
    - Frontend application
    - Database

---

## **CoinGecko API**

- **Current Tier**: Free Account ($0/month)

  - **License**: Non-commercial
  - **Monthly API Calls**: 0 / 10,000
  - **Remaining API Calls**: 10,000
  - **Rate Limit**: 30 requests per minute

- **Potential Upgrade**: Analyst Plan ($129/month)

  - **License**: Commercial
  - **Features**:
    - Higher rate limit (500 requests per minute)
    - Access to advanced market data endpoints
    - Suitable for medium-scale commercial applications

- **Functions**:
  - Fetch real-time USD/SOL exchange rates
  - Provide accurate cryptocurrency price data for calculations

---

## **Google Maps API**

- **Current Tier**: Free Account (0–10,000 monthly calls)
- **Potential Upgrade**: $254.70/month for higher usage limits

- **Functions**:
  - Fetch geolocation data for property pages (e.g., `/assets/[id]`)
  - Display maps and location markers for user assets
