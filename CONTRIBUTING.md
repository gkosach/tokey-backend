## For ToKey Employees/Contractors

### Code Ownership

- All code contributions become property of ToKey Platform
- By contributing, you assign all rights to ToKey Platform
- Your employment/contract agreement governs your contributions

### Confidentiality

- All code and business logic are confidential
- Do not share, discuss, or disclose outside ToKey Platform
- Use only for authorized ToKey Platform projects

### Development Guidelines

- Follow established coding standards
- Document all changes thoroughly
- Obtain approval for architectural changes
- Report security issues immediately
